
1. Project Title
Library Book Issue System

2. Introduction
The Library Book Issue System is a simple system used to manage the
process of issuing books to students or library members. It stores
book details, student details, issue dates and due dates.

3. Objectives
- To issue books easily.
- To maintain student and book records.
- To record the issue date and due date.
- To reduce manual work.
- To maintain accurate library records.

4. Main Entities
- Student
- Book
- Librarian
- Book Issue
- Department

5. Book Issue Details
The system stores:
- Issue ID
- Student ID
- Book ID
- Issue Date
- Due Date
- Librarian ID
- Return Status

6. Working
1. Student requests a book.
2. Librarian checks book availability.
3. If the book is available, it is issued to the student.
4. The issue date and due date are recorded.
5. The book status is changed to "Issued".
6. When the book is returned, its status is changed to "Available".

7. Advantages
- Easy to manage book issues.
- Saves time.
- Reduces paperwork.
- Provides accurate records.
- Makes book tracking easier.

8. Requirements
Hardware:
- Computer
- Keyboard and Mouse

Software:
- Operating System
- Database Management System
- Programming Language

9. Conclusion
